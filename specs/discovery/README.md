# Discovery

This folder tracks unresolved product questions that need explicit decisions.

## Workflow

- Capture questions as soon as uncertainty is discovered.
- Link each question to related feature specs.
- Record a decision outcome and update impacted specs immediately.
- Keep only unresolved questions in this discovery area.
- After a decision is applied to specs, remove the resolved question from `open-questions.md`.
- Use real relative Markdown links for every related-spec reference.

## Files

- [open-questions.md](./open-questions.md): prioritized decision backlog for product refinement.
